<objective>
## Goal
Upgrade HeroSpotlight to auto-rotate through multiple hero entries with a particle canvas background and a click-to-preview modal, and update HomeHeader's primary CTA to "Watch free for 7 days" with a pulsing glow animation.

## Purpose
These are the conversion-critical elements of the Phase 2 homepage redesign. The existing homepage has content rails, proof strip, and rankings, but the hero is static and the CTA copy doesn't communicate the free-trial value proposition. Auto-rotation keeps the hero alive. The preview modal converts curiosity into intent. The CTA copy change is the single highest-impact conversion copy update.

## Output
- `types.ts` — `HeroCarouselData` type, `HomeSection` updated to use it
- `homepage.data.ts` — hero converted from single entry to carousel array (3 entries)
- `HeroSpotlight.tsx` — Client Component with auto-rotation (5s interval, fade), particle canvas overlay, modal trigger on poster click
- `HeroPreviewModal.tsx` — new Client Component: full-screen overlay with show details + CTAs
- `SectionRenderer.tsx` — passes `HeroCarouselData` to `HeroSpotlight`
- `HomeHeader.tsx` — primary CTA: "Watch free for 7 days" + `animate-pulse-glow` class
</objective>

    - Update the `hero` case: pass `section.data` (which is now `HeroCarouselData`) as `carousel` prop to `HeroSpotlight`. Change prop name from `hero={section.data}` to `carousel={section.data}`.

    **Step 4 — Rewrite HeroSpotlight.tsx:**
    - Add `"use client"` directive at top (required for useState, useEffect, useRef)
    - Change prop: `({ carousel }: { carousel: HeroCarouselData })`
    - Add: `const [activeIndex, setActiveIndex] = useState(0)`
    - Add: `const [isTransitioning, setIsTransitioning] = useState(false)`
    - Add: `const canvasRef = useRef<HTMLCanvasElement>(null)`
    - Auto-rotation useEffect: setInterval every 5000ms. On tick: setIsTransitioning(true), after 200ms setActiveIndex((i) => (i + 1) % carousel.entries.length), after 400ms setIsTransitioning(false). Clear interval on cleanup.
    - Derive current entry: `const hero = carousel.entries[activeIndex]`
    - Render the existing JSX with `hero` (same as before), wrapped in a div with transition class. Apply `opacity-0` during transition, `opacity-100` otherwise, with `transition-opacity duration-400`.
    - Add a `<canvas ref={canvasRef} className="absolute inset-0 pointer-events-none z-0 opacity-40" />` INSIDE the section's `relative overflow-hidden` container, BEFORE all content divs.
    - Particle canvas useEffect: runs once on mount (no dependency). Create ~40 particles: each `{ x, y, vx, vy, radius, opacity }`. Initialize randomly across canvas width/height. Each frame: update x += vx, y += vy, bounce at edges. Draw filled circles with `ctx.fillStyle = 'rgba(113, 199, 4, 0.18)'`. Use `requestAnimationFrame`. Canvas size: sync to parent div via ResizeObserver or set `canvas.width = canvas.offsetWidth; canvas.height = canvas.offsetHeight` in the effect. Cancel animation frame on cleanup.
    - Existing gradient backgrounds on the `<section>` stay — particles layer on top of them.
    - Add `onPosterClick` prop to the image container (the inner div wrapping `<Image>`) — for now set `onClick={() => {}}` placeholder (Task 2 will wire the real handler).

    Avoid: using `window` directly (use `canvas.offsetWidth`), using `as any` casts, using direct DOM manipulation outside the ref.
