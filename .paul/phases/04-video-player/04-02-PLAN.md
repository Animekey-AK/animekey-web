<task type="auto" id="2">
Update WatchPageClient for episode selection

Add state:
```tsx
const [activeEpisode, setActiveEpisode] = useState(show.episodes[0]);
```

- Pass `activeEpisode.number` into a new `selectedEpisode` prop on EpisodeList (so it can highlight the active card)
- When an episode card is clicked:
  - If `episode.isFree` → `setActiveEpisode(episode)` (player switches)
  - If `!episode.isFree` → scroll to paywall strip (don't switch player)
- Pass `activeEpisode` data to VideoPlayer `title` and `poster` props
- Resume: on episode change, read `localStorage.getItem(\`resume:${show.slug}:${activeEpisode.number}\`)` and pass as `initialTime`
- Save: VideoPlayer calls `onTimeUpdate` callback → debounce (every 5s) → `localStorage.setItem(\`resume:${show.slug}:${activeEpisode.number}\`, currentTime.toString())`

Add `onTimeUpdate` prop to VideoPlayer:
```tsx
onTimeUpdate?: (currentTime: number) => void;
```
Call it in the existing `timeupdate` event handler.
</task>

Render a toggle below the episode info / above the episode list:
```tsx
<div className="flex gap-1 rounded-full border border-white/10 bg-white/[0.03] p-1">
  {(["sub", "dub"] as const).map((lang) => (
    <button
      key={lang}
      onClick={() => setLanguage(lang)}
      className={cn(
        "rounded-full px-4 py-1.5 text-[12px] font-semibold uppercase tracking-wide transition-colors",

          : "text-white/40 hover:text-foreground",

      {lang}
    </button>
  ))}
```
