<task type="auto" id="2">
Add keyboard shortcut overlay to VideoPlayer

Add to state: `const [showShortcuts, setShowShortcuts] = useState(false)`

In the existing keyboard shortcut `useEffect`, add a case for `?`:
```tsx
case "?":
  e.preventDefault();
  setShowShortcuts((v) => !v);
  break;
```

Also close on Escape (add to existing Escape handling or add new case).

Render the overlay:
```tsx
{showShortcuts && (
  <div
    className="absolute inset-0 flex items-center justify-center bg-black/80 backdrop-blur-sm"
    onClick={() => setShowShortcuts(false)}
  >
    <div
      className="rounded-2xl border border-white/10 bg-[rgba(10,10,10,0.95)] p-6 shadow-2xl"
      onClick={(e) => e.stopPropagation()}
    >
      <div className="mb-4 flex items-center justify-between">
        <h3 className="text-[14px] font-bold text-foreground">Keyboard shortcuts</h3>
        <button onClick={() => setShowShortcuts(false)} className="text-white/40 hover:text-white">✕</button>
      </div>
      <div className="grid grid-cols-2 gap-x-8 gap-y-2.5">
        {[
          ["Space / K", "Play / Pause"],
          ["← / →", "Seek ±10 seconds"],
          ["↑ / ↓", "Volume ±10%"],
          ["M", "Mute / Unmute"],
          ["F", "Fullscreen"],
          ["?", "Show shortcuts"],
        ].map(([key, desc]) => (
          <div key={key} className="flex items-center gap-3">
            <kbd className="min-w-[48px] rounded border border-white/20 bg-white/8 px-2 py-1 text-center text-[11px] font-mono text-white/70">
              {key}
            </kbd>
            <span className="text-[12px] text-foreground/60">{desc}</span>
          </div>
        ))}
      </div>
    </div>
  </div>
)}
```
