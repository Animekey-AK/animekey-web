<task type="auto" id="2">
Create VideoPlayer component

File: apps/web/components/player/VideoPlayer.tsx

"use client" component using dynamic import of hls.js (to avoid SSR issues).

Interface:
```tsx
interface Props {
  src: string;          // HLS manifest URL (or direct MP4 for dev)
  poster?: string;      // Poster image before play
  title?: string;       // Episode title for aria-label
  onEnded?: () => void; // Called when episode ends
}
```

Implementation:
- `useRef<HTMLVideoElement>` for the video element
- `useEffect` to init Hls: if `Hls.isSupported()` → attach HLS; else if native HLS (Safari) → set `video.src` directly
- Cleanup: `hls.destroy()` on unmount
- Custom controls overlay (absolutely positioned, visible on hover / always on mobile):
  - Play/pause button (SVG triangle / two bars)
  - Seek bar: `<input type="range">` synced to `video.currentTime / video.duration`
  - Current time / duration display: `1:23 / 24:00`
  - Volume button + slider (hidden on mobile)
  - Fullscreen button (SVG expand icon)
- Keyboard shortcuts via `useEffect` on `window.keydown`:
  - Space → toggle play/pause
  - ArrowRight → seek +10s
  - ArrowLeft → seek -10s
  - ArrowUp/Down → volume ±0.1
  - F → fullscreen toggle
- States: `playing`, `currentTime`, `duration`, `volume`, `buffered`, `showControls`
- `showControls` auto-hides after 3s of no mouse movement (mousemove resets timer)
- Loading spinner shown while `readyState < 3`

Styling (Tailwind):
- `relative aspect-video w-full overflow-hidden rounded-2xl bg-black`
- Controls: `absolute inset-x-0 bottom-0 bg-gradient-to-t from-black/80 to-transparent px-4 pb-4 pt-16`
- Seek bar: custom range input via Tailwind (accent-primary)
- On mobile: controls always visible

For dev: if no real HLS URL available, accept `src` as a direct MP4 link (hls.js falls through to native).
</task>
