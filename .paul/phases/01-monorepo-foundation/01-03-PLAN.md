<objective>
## Goal
Create `packages/tokens` (design token definitions — JS export usable by web and mobile) and `packages/config` (shared TypeScript base config), then wire `apps/web` to consume them.

## Purpose
The monorepo has no shared packages yet. This plan creates the single source of truth for design tokens that both `apps/web` (via Tailwind theme extension) and `apps/mobile` (via React Native StyleSheet) will consume. It also establishes a shared tsconfig base so all workspace packages start from consistent TypeScript settings.

## Output
- `packages/tokens/` — TypeScript-first package exporting colors, typography, spacing, animation tokens
- `packages/config/` — shared tsconfig.base.json
- `apps/web/tailwind.config.ts` updated to import brand/surface tokens from `@animekey/tokens`
- `apps/web/tsconfig.json` extended from `@animekey/config/tsconfig.base.json`
- `pnpm typecheck` passes for apps/web after wiring
</objective>

    ```typescript
    export const colors = {
      brand: {
        DEFAULT: "#71C704",
        50:  "#f4fce3",

        overlay: "#212121",
      },
    } as const;

    // Typography — base font stacks without CSS var wrappers (those are web-only)
    export const fontFamily = {
      sans:        ["Inter", "system-ui", "sans-serif"],
      display:     ["Anton", "sans-serif"],
      description: ["Montserrat", "sans-serif"],
      mono:        ["monospace"],
    } as const;

    export const fontSize = {
      hero:       ["6rem",    { lineHeight: "1.1",  fontWeight: "400" }],
      display:    ["2.25rem", { lineHeight: "1.1",  fontWeight: "700" }],
      "title-lg": ["2rem",    { lineHeight: "1.1",  fontWeight: "700" }],
      title:      ["1.875rem",{ lineHeight: "1.21", fontWeight: "700" }],
      "title-sm": ["1.375rem",{ lineHeight: "1.1",  fontWeight: "700" }],
      label:      ["1rem",    { lineHeight: "1.45", fontWeight: "500" }],
    } as const;

    // Border radius
    export const borderRadius = {
      sm:   "calc(var(--radius) - 4px)",
      md:   "calc(var(--radius) - 2px)",
      lg:   "var(--radius)",
      xl:   "calc(var(--radius) + 4px)",
      "2xl":"calc(var(--radius) + 8px)",
    } as const;

    // Keyframe animations
    export const keyframes = {
      "fade-in":  { from: { opacity: "0" }, to: { opacity: "1" } },
      "slide-up": {
        from: { transform: "translateY(8px)", opacity: "0" },
        to:   { transform: "translateY(0)",   opacity: "1" },
      },
    } as const;

    export const animation = {
      "fade-in":  "fade-in 0.2s ease-out",
      "slide-up": "slide-up 0.25s ease-out",
    } as const;

    // Convenience: all tokens in one object (for mobile StyleSheet usage)
    export const tokens = {
      colors,
      fontFamily,
      fontSize,
      borderRadius,
      keyframes,
      animation,
    } as const;
    ```

    Note on borderRadius: the CSS var references (var(--radius)) are intentional —
    they're set by shadcn/ui CSS custom properties and must remain as-is for web.
    Mobile will define its own numeric radius values when Expo is set up in Phase 9.

  <action>
    **Step 1 — Add workspace dependencies to apps/web/package.json:**
    Add to the `dependencies` section:
    ```json
    "@animekey/tokens": "workspace:*"
    ```
    Add to the `devDependencies` section:
    ```json
    "@animekey/config": "workspace:*"
    ```

    **Step 2 — Update apps/web/tailwind.config.ts:**
    Add import at the top:
    ```typescript
    import { colors, fontFamily, fontSize, borderRadius, keyframes, animation } from "@animekey/tokens";
    ```

    In the `theme.extend` block, replace the hardcoded brand/surface values with token imports:
    - Replace the `brand:` and `surface:` blocks inside `colors:` with spread from tokens:
      `...colors,` (spread the entire colors object — this adds brand and surface alongside the CSS var colors)
    - Replace `fontFamily` block content with imported `fontFamily` — but keep the CSS var wrappers
      for the web app:
      ```typescript
      fontFamily: {
        sans:        [`var(--font-sans)`, ...fontFamily.sans],
        display:     [`var(--font-display)`, ...fontFamily.display],
        description: [`var(--font-description)`, ...fontFamily.description],
        mono:        [`var(--font-mono)`, ...fontFamily.mono],
      },
      ```
    - Replace `fontSize` block with `...fontSize`
    - Replace `borderRadius.sm/md/lg/xl/2xl` values with `...borderRadius`
    - Replace `keyframes` block with `...keyframes`
    - Replace `animation` block with `...animation`

    Keep all CSS variable colors (`background`, `foreground`, `card`, etc.) exactly as they are —
    those are shadcn/ui semantic colors, not brand tokens.

    **Step 3 — Update apps/web/tsconfig.json:**
    Add `"extends": "@animekey/config/tsconfig.base.json"` as the first field.
    Keep all existing `compilerOptions` — they override/extend the base.

    **Step 4 — Run pnpm install to link new workspace packages:**
    ```
    pnpm install
    ```

    **Step 5 — Run typecheck:**
    ```
    pnpm --filter @animekey/web typecheck
    ```
    Must exit 0.

    Do NOT change the CSS var semantic colors in tailwind.config.ts.
    Do NOT change any files in apps/web/app/, components/, lib/, etc.
