## Goal
Move the Next.js web app from the repo root into `apps/web/`, rename its package to `@animekey/web`, create a lean monorepo root `package.json`, and install dependencies with pnpm so the workspace resolves correctly.

## Purpose
The workspace scaffold (01-01) declared `apps/*` and `packages/*` but the web app is still sitting at the root. This plan completes the physical migration — after it, `pnpm --filter @animekey/web dev` starts the app and the repo is a real monorepo.

## Output
- All Next.js app files moved to `apps/web/`
- `apps/web/package.json` name changed to `@animekey/web`
- New root `package.json` with turbo scripts
- `pnpm-lock.yaml` generated at repo root
- `package-lock.json` deleted
- Dev server confirmed working at localhost:3000
</objective>

<task type="auto">
  <name>Task 1: Move web app files to apps/web/ via git mv</name>
  <files>
    apps/web/app, apps/web/components, apps/web/lib, apps/web/hooks,
    apps/web/services, apps/web/actions, apps/web/constants, apps/web/types,
    apps/web/public, apps/web/next.config.ts, apps/web/tsconfig.json,
    apps/web/tailwind.config.ts, apps/web/postcss.config.mjs,
    apps/web/eslint.config.mjs, apps/web/auth.config.ts, apps/web/proxy.ts,
    apps/web/components.json, apps/web/package.json
  </files>
  <action>
    Create the destination directory first:
    ```
    mkdir -p apps/web
    ```

    Move all tracked source directories in one git mv call:
    ```
    git mv app components lib hooks services actions constants types public apps/web/
    ```

    Move all tracked config files:
    ```
    git mv next.config.ts tsconfig.json tailwind.config.ts postcss.config.mjs eslint.config.mjs auth.config.ts proxy.ts components.json package.json apps/web/
    ```

    Remove stale root-level build artifacts (these are tracked but stale after the move):
    ```
    git rm package-lock.json next-env.d.ts tsconfig.tsbuildinfo 2>/dev/null || true
    ```

    Move .env.local if it exists on disk (it's gitignored so git mv won't handle it):
    ```
    [ -f .env.local ] && mv .env.local apps/web/.env.local || true
    ```

    Do NOT move: .gitignore, README.md, CLAUDE.md, pnpm-workspace.yaml, turbo.json,
    .paul/, docs/, output/, apps/, packages/ — these stay at root.

    Reason for git mv over regular mv: preserves file history in git log.
    Reason to remove package-lock.json: npm lock file is incompatible with pnpm workspaces.
    Reason next-env.d.ts is removed: Next.js auto-generates it in apps/web/ on first run.
  </action>
  <verify>
    ls apps/web/ should show: app  auth.config.ts  components  components.json
    constants  eslint.config.mjs  hooks  lib  next.config.ts  package.json
    postcss.config.mjs  proxy.ts  public  services  tailwind.config.ts  tsconfig.json  types

    ls app 2>&1 should say "No such file or directory" (root app/ is gone)
    ls next.config.ts 2>&1 should say "No such file or directory"
  </verify>
  <done>AC-1 satisfied: all web app files in apps/web/, none remaining at root</done>
</task>

    **Step 2 — Create root package.json:**
    Create a NEW `package.json` at the repo root (this is NOT a move — it's a new file):
    ```json
    {
      "name": "animekey-root",
      "version": "0.0.0",
      "private": true,
      "scripts": {
        "dev": "turbo dev",
        "build": "turbo build",
        "typecheck": "turbo typecheck",
        "lint": "turbo lint"
      },
      "devDependencies": {
        "turbo": "latest"
      }
    }
    ```

    **Step 3 — Run pnpm install:**
    ```
    pnpm install
    ```
    This generates `pnpm-lock.yaml` at the repo root and installs all workspace packages.
    If pnpm is not installed: `npm install -g pnpm` first, then retry.

    Do NOT modify any other files in apps/web/ — scripts, dependencies,
    tsconfig paths, and next.config.ts are all correct as-is.

    Reason name is @animekey/web: turbo --filter flag matches by package name,
    so `pnpm --filter @animekey/web dev` routes to this workspace.
  </action>
  <verify>
    cat apps/web/package.json | grep '"name"' → should show "@animekey/web"
    cat package.json | grep '"name"' → should show "animekey-root"
